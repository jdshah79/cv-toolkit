# cv-toolkit
Collection of CV solutions for practical applications

Tech: PyTorch, OpenCV, YOLO
Use Cases: Object detection, image classification, segmentation

How to Run It
1. Install Requirements: Make sure you have Flask and Ultralytics (YOLO) installed in your environment.
     pip install flask ultralytics opencv-python torch

2. Launch the Server: Run your script from your terminal.
    python app.py

3. Open the Webpage: Open your web browser and go to:
      http://127.0.0.1:5000/

Your browser will load the HTML layout, your webcam will turn on, and you will see a live video feed tracking you and objects around your room with bounding boxes in real-time!
